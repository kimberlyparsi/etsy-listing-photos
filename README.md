# etsy-listing-photos

The hero listing photo for the Co-Parenting Custody Tracker, built in GIMP from layers so I can re-edit it without starting over.

`custody-tracker-hero.xcf` is the working file. Six layers, bottom to top:

1. `plate-1-background.png` — plain cream plate
2. `plate-2-card.png` — the white card + shadow the screenshot sits on
3. `plate-3-screenshot.png` — an ACTUAL screenshot of the spreadsheet (the demo tab, filled in)
4. `plate-4-title-text.png` — title block
5. `plate-5-bottom-text.png` — the lines under the card + the red download band
6. `plate-6-badge.png` — the Instant Download seal (from my Inkscape brand kit)

The pieces live in `plates/` and `custody-tracker-hero-gimp.png` is the flattened export that goes on Etsy. Everything is 2000x2000 because that's Etsy's zoom size.

## My one rule

Real screenshots only. No fake mockups of a product that doesn't look like that — buyers can tell, and so can I.

First version of this photo clipped the dates off the screenshot and cut the chart legend in half on the dashboard shot. Scrapped it, rebuilt the set, checked every image at 100% before uploading. The layered file is how I never have to redo the whole thing again — swap the screenshot layer, re-export, done.
